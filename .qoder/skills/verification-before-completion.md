# verification-before-completion（完成前验证）

## 何时触发

- 任何任务/变更宣称"完成"之前（强制性，见 `.qoder/rules/quality-gates.md`）

## 执行方式

1. 对照验收标准逐条验证：跑测试、跑程序、看输出
2. 证据必须是真实执行结果（命令输出、测试通过列表），不能是推断
3. 验证失败 → 回到实施/调试，修正后再验证
4. 验证通过 → 汇报：验证了什么、证据是什么、还有哪些未覆盖

## 反模式（禁止）

- "应该可以了"式结论
- 只写测试不运行
- 用旧的执行结果冒充本次验证
